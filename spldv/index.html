Konsep Dasar

Apa itu SPLDV?

Sistem Persamaan Linear Dua Variabel (SPLDV) adalah kumpulan dua persamaan linear yang memiliki dua variabel yang sama, biasanya x dan y. Bentuk umumnya:

a1x + b1y = c1 a2x + b2y = c2

Pasangan nilai (x, y) yang membuat kedua persamaan bernilai benar disebut himpunan penyelesaian (HP). Setiap persamaan linear, kalau digambar, membentuk sebuah garis lurus — jadi menyelesaikan SPLDV sama artinya dengan mencari titik tempat kedua garis itu berpotongan.

Ada 3 kemungkinan hasil SPLDV:
1. Kedua garis berpotongan di satu titik → satu penyelesaian.
2. Kedua garis sejajar → tidak ada penyelesaian.
3. Kedua garis berimpit (garis yang sama) → tak hingga penyelesaian.

Metode 1

Metode Grafik

Gambar kedua garis pada satu bidang koordinat. Koordinat titik potongnya adalah penyelesaian SPLDV.

Contoh: tentukan HP dari

x + y = 5 x − y = 1

  1. Untuk garis x + y = 5, cari dua titik mudah: jika x = 0 maka y = 5 → titik (0, 5). Jika y = 0 maka x = 5 → titik (5, 0).
  2. Untuk garis x − y = 1: jika x = 0 maka y = −1 → titik (0, −1). Jika y = 0 maka x = 1 → titik (1, 0).
  3. Gambar kedua garis dengan menghubungkan titik-titik tersebut, seperti pada grafik di atas.
  4. Kedua garis berpotongan tepat di titik (3, 2).
  5. Periksa: 3 + 2 = 5 ✓ dan 3 − 2 = 1 ✓. Keduanya benar, jadi HP = {(3, 2)}.
Metode 2

Metode Eliminasi

Hilangkan (eliminasi) salah satu variabel dengan menjumlahkan atau mengurangkan kedua persamaan, setelah koefisiennya disamakan.

Contoh: tentukan HP dari

2x + y = 7 x + 2y = 8

  1. Beri nama: persamaan (1) adalah 2x + y = 7, persamaan (2) adalah x + 2y = 8. Kita akan mengeliminasi variabel x.
  2. Samakan koefisien x: kalikan persamaan (2) dengan 2, menjadi 2x + 4y = 16.
  3. Kurangkan persamaan (1) dari hasil itu: (2x + 4y) − (2x + y) = 16 − 7, sehingga 3y = 9 dan y = 3.
  4. Substitusikan y = 3 ke persamaan (1): 2x + 3 = 7 → 2x = 4 → x = 2.
  5. Periksa ke persamaan (2): 2 + 2(3) = 8 ✓. Jadi HP = {(2, 3)}.
Metode 3

Metode Substitusi

Nyatakan satu variabel dalam variabel lain, lalu masukkan (substitusikan) ke persamaan berikutnya sampai tersisa satu variabel.

Contoh: tentukan HP dari

x + y = 8 y = 2x − 1

  1. Persamaan (2) sudah menyatakan y dalam x: y = 2x − 1. Ini memudahkan substitusi.
  2. Substitusikan y = 2x − 1 ke persamaan (1): x + (2x − 1) = 8.
  3. Selesaikan: 3x − 1 = 8 → 3x = 9 → x = 3.
  4. Substitusikan x = 3 ke persamaan (2): y = 2(3) − 1 = 5.
  5. Periksa: 3 + 5 = 8 ✓. Jadi HP = {(3, 5)}.
Dalam praktiknya, ketiga metode boleh digabung: eliminasi dulu untuk mencari satu variabel, lalu substitusi untuk variabel lainnya. Coba di menu Kalkulator!
