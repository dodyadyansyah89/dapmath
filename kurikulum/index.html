Selamat datang

Aplikasi ini membantu 45 guru SMP Negeri 171 Jakarta mengumpulkan perangkat ajar dan menyusunnya dengan generator, serta membantu Wakil Kepala Sekolah bidang Kurikulum memantau semuanya dari satu dasbor. Data terpusat di Google Spreadsheet sekolah melalui Apps Script Web App — pasang URL-nya di menu Pengaturan & Panduan. Tanpa URL pun aplikasi tetap bisa dipakai: pengumpulan tersimpan di perangkat ini dan dokumen tetap bisa diunduh.

Modul 1 — Pengumpulan Perangkat Ajar

Guru masuk dengan nama dan mata pelajaran, lalu mengirimkan tautan Google Drive dokumen ATP, RPP, instrumen asesmen, atau dokumen lainnya per kelas dan semester. Wakil kurikulum memantau rekapnya di dasbor yang terkunci PIN.

Modul 2 — Generator Perangkat Ajar (AI)

Inputnya minimal: untuk ATP guru cukup menentukan materi pokok — capaian pembelajaran, tujuan pembelajaran, kelas, semester, dan alokasi waktu disusun oleh AI (Gemini). Untuk RPP guru cukup mengisi identitas diri, materi, dan kelas — selebihnya di-generate AI, lalu ditinjau dan diedit sebelum diunduh sebagai Word (.docx) atau PDF. Fitur AI memerlukan URL Web App terpasang dan GEMINI_API_KEY di Apps Script (lihat Pengaturan & Panduan).

Modul 3 — Nilai & Raport

Kelola data siswa, rentang predikat, input nilai per mapel, catatan wali dan absensi, lalu cetak kartu laporan hasil belajar per kelas dan rekap leger nilai. Data nilai tersimpan di perangkat ini dan dapat dibagikan lewat ekspor/impor CSV.

Formulir Pengumpulan Perangkat Ajar

Unggah dulu dokumen Bapak/Ibu ke Google Drive, lalu tempel tautannya di sini. Pastikan izin berbagi Drive diatur agar Wakil Kurikulum dapat membuka dokumennya.

Isi minimal salah satu: tautan Drive atau keterangan file.

Database Pusat — Google Spreadsheet

Mengikuti pola aplikasi DapMath: buat satu Google Spreadsheet, tempel kode Apps Script yang disediakan di bawah, deploy sebagai Web App, lalu tempel URL-nya di sini. Setelah terpasang, setiap pengumpulan guru dan metadata dokumen dari generator otomatis tercatat di spreadsheet pusat dan bisa dimuat ke dasbor dari perangkat mana pun.

Panduan Deploy Apps Script

  1. Buat Google Spreadsheet baru (mis. “Database Kurikulum SMPN 171”) di akun Google sekolah/guru.
  2. Di spreadsheet itu, klik menu Extensions → Apps Script.
  3. Hapus isi editor, lalu tempel seluruh kode di bawah ini. Klik Save.
  4. Untuk fitur AI: di editor Apps Script, buka Project Settings → Script Properties → Add script property, isi Property = GEMINI_API_KEY dan Value = kunci Gemini pemilik spreadsheet. Kunci ini tersimpan aman di sisi server Apps Script dan tidak pernah tertanam di halaman web ini.
  5. Klik Deploy → New deployment → Web app. Isi: Execute as = Me, Who has access = Anyone. Klik Deploy, lalu setujui izin akses (Run pertama memerlukan izin “Connect to an external service” — jalankan fungsi ujiIzin sekali dari editor bila diminta).
  6. Salin Web app URL yang muncul dan tempel pada kolom URL di atas, lalu klik Uji Kirim Data Sekarang.
  7. Setiap mengubah kode, ulangi Deploy → Manage deployments → Edit → New version agar perubahan aktif.

        

        

          
Fitur AI — Gemini lewat Apps Script

          
Tombol Generate ATP dengan AI dan Generate RPP dengan AI pada generator bekerja dengan memanggil Web App yang sama dengan database pusat. Kode Apps Script di bawah sudah memuat dua aksi baru:

          
    
            
  1. generateATP — input: materi pokok (dan mata pelajaran sebagai konteks). Output JSON: capaian pembelajaran, daftar tujuan pembelajaran berurutan, kelas, semester, dan alokasi waktu per tujuan.

  2. generateRPP — input: identitas guru, materi, dan kelas. Output JSON: seluruh isi RPP Pembelajaran Mendalam bagian A (Identifikasi), B (Desain Pembelajaran), C (Pengalaman Belajar per pertemuan), dan D (Asesmen).
    3. 
          

          
Bila URL Web App belum dipasang atau GEMINI_API_KEY belum ada di Script Properties, tombol Generate tidak mengarang hasil — aplikasi hanya menampilkan penjelasan dan langkah aktivasinya. Hasil generate selalu ditampilkan dulu untuk ditinjau dan diedit guru sebelum diunduh.

        

        

          
Catatan Penyimpanan

          
Data yang tersimpan di perangkat ini (riwayat pengumpulan lokal, draf generator, daftar nama guru, dan PIN dasbor) hanya ada di browser perangkat ini — sama seperti batasan aplikasi DapMath sebelumnya. Agar data terpusat dan bisa diakses lintas perangkat, pasang URL Web App di atas. PIN dasbor adalah gerbang praktis untuk kelas/sekolah, bukan enkripsi; spreadsheet pusat tetap hanya bisa dibuka lewat akun Google pemiliknya.
