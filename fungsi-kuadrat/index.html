📈 Mengenal Fungsi Kuadrat

Fungsi kuadrat adalah fungsi yang pangkat tertinggi variabelnya dua. Grafiknya berbentuk parabola — kurva melengkung mulus seperti lintasan bola yang ditendang ke udara!

Bentuk Umum

f(x) = ax² + bx + c
  • a, b, c adalah bilangan nyata, dan a ≠ 0 (kalau a = 0, grafiknya jadi garis lurus, bukan parabola).
  • c menentukan titik potong grafik dengan sumbu Y, yaitu titik (0, c).
  • Contoh: f(x) = x² − 4x + 3, dengan a = 1, b = −4, c = 3.

🎯 Pengaruh Nilai a

  • Jika a > 0 → parabola terbuka ke atas (seperti mangkuk 😊), punya nilai minimum.
  • Jika a < 0 → parabola terbuka ke bawah (seperti payung ☂️), punya nilai maksimum.
  • Makin besar nilai |a|, parabola makin sempit; makin kecil, makin lebar.

Coba buktikan sendiri di menu Lab Parabola dengan menggeser slider a!

⭐ Titik Puncak & Nilai Optimum

Titik tertinggi atau terendah parabola disebut titik puncak. Nilai y pada puncak disebut nilai optimum (maksimum atau minimum).

Titik puncak: ( −b/2a , −D/4a )
  • Sumbu simetri: garis x = −b/2a yang membagi parabola menjadi dua bagian sama persis.
  • Diskriminan: D = b² − 4ac.
  • Nilai optimum: yp = −D/4a.

✂️ Titik Potong dengan Sumbu X

Titik potong dengan sumbu X disebut pembuat nol fungsi, diperoleh saat f(x) = 0. Banyaknya ditentukan oleh diskriminan:

  • D > 0  memotong sumbu X di dua titik berbeda.
  • D = 0  menyinggung sumbu X di satu titik.
  • D < 0  tidak memotong sumbu X sama sekali.

🏀 Fungsi Kuadrat di Kehidupan Sehari-hari

  • Lintasan bola basket, sepak bola, dan air mancur yang berbentuk parabola.
  • Jembatan gantung dan antena parabola penangkap sinyal.
  • Menghitung keuntungan maksimum dalam usaha (nilai optimum).
  • Gerak proyektil — akan kamu simulasikan di menu Simulasi Proyektil!
Ingat: pada gerak proyektil, tinggi maksimum bola adalah nilai optimum dari fungsi kuadrat ketinggiannya. Titik puncak lintasan = titik tertinggi bola! 🎯

🧠 Contoh Cepat

Untuk f(x) = x² − 6x + 5 (a = 1, b = −6, c = 5):

  • Sumbu simetri: x = −(−6)/(2·1) = 3
  • D = (−6)² − 4·1·5 = 36 − 20 = 16
  • Nilai minimum: yp = −16/(4·1) = −4, jadi titik puncaknya (3, −4)
  • Pembuat nol: x² − 6x + 5 = (x − 1)(x − 5) → x = 1 atau x = 5
  • Titik potong sumbu Y: (0, 5)
