Bentuk Umum Persamaan Kuadrat

Persamaan kuadrat adalah persamaan yang pangkat tertinggi variabelnya adalah dua. Bentuk umumnya:

ax² + bx + c = 0
a = koefisien x²
syarat: a ≠ 0
b = koefisien x
c = konstanta (suku bebas)

Kenali Koefisiennya!

Persamaan: 3x² − 5x + 2 = 0. Tuliskan nilai a, b, dan c-nya:

Ingat tanda minusnya! Pada 3x² − 5x + 2 = 0, nilai b adalah −5 (bukan 5), karena tanda di depan suku ikut menjadi milik koefisiennya.

Tiga Cara Menyelesaikan Persamaan Kuadrat

1. Pemfaktoran

2. Kuadrat Sempurna

Lab Parabola

Geser slider a, b, dan c lalu perhatikan: grafik fungsi f(x) = ax² + bx + c berubah langsung! Titik hijau adalah akar-akar (titik potong dengan sumbu-x), titik merah muda adalah titik puncak.

f(x) = x² − 3x + 2

Pemfaktoran: Tebak Dua Bilangan!

Untuk memfaktorkan x² + px + q, kita mencari dua bilangan yang hasil kalinya = q dan jumlahnya = p. Yuk bermain: tebak dua bilangan untuk soal di bawah ini!

x² + 5x + 6 = 0

Cari dua bilangan yang dikalikan hasilnya 6 dan dijumlahkan hasilnya 5.

Skor permainan: 0
Ronde: 1
Percobaan ronde ini: 0

Langkah Pemfaktorannya

    Trik cepat: mulai dari pasangan faktor dari q. Misalnya q = 6 → pasangan (1,6), (2,3), (−1,−6), (−2,−3). Cek pasangan mana yang jumlahnya sama dengan p!

    Melengkapkan Kuadrat Sempurna

    Metode ini mengubah x² + bx menjadi bentuk kuadrat sempurna (x + b/2)² dengan menambahkan (b/2)² di kedua ruas. Ikuti langkahnya satu per satu!

    Persamaan yang akan diselesaikan: x² + 6x + 5 = 0 (koefisien a = 1)

      Mengapa ditambah (b/2)²? Karena (x + b/2)² = x² + bx + (b/2)². Menambah (b/2)² "melengkapkan" ruas kiri menjadi kuadrat sempurna — dan supaya persamaan tetap setara, ruas kanan juga harus ditambah nilai yang sama.

      Rumus ABC

      Rumus andalan untuk mencari akar-akar persamaan kuadrat ax² + bx + c = 0:

      x = (−b ± √D) / 2a,  D = b² − 4ac

      Persamaan: x² − 3x + 2 = 0

        Diskriminan & Jenis-Jenis Akar

        Diskriminan adalah nilai D = b² − 4ac. Tanpa menyelesaikan persamaan, D memberi tahu kita jenis akar-akarnya — dan bentuk parabolanya!

        D > 0 — dua akar real berbeda. Parabola memotong sumbu-x di 2 titik.
        D = 0 — dua akar real kembar (sama). Puncak parabola tepat menyinggung sumbu-x.
        D < 0 — tidak punya akar real. Parabola melayang, tidak menyentuh sumbu-x.
